# agent-audit — инвентарь скиллов, launchd-агентов и Python-скриптов

Один запуск на Маке → отчёт, что у тебя вообще крутится, что давно не используется и что сломано.
Только чтение: содержимое скриптов и секреты в отчёт не попадают.

## Запуск

```bash
python3 agent_audit.py                          # сканирует весь $HOME (без Library, venv, node_modules…)
python3 agent_audit.py --roots ~/b360 ~/scripts # только нужные папки — быстрее
python3 agent_audit.py --stale-days 30          # порог «сироты» (по умолчанию 60 дней)
```

Результат: `~/agent-audit/audit-YYYY-MM-DD.md` (читать) и `.json` (для разбора).

## Что собирает

| Раздел | Откуда | Что видно |
|---|---|---|
| Скиллы | `~/.claude/skills`, `~/.claude/plugins`, `.claude/skills` в репо | последний вызов, вызовов за 30/90 дней, когда правили |
| Вызовы скиллов | журналы Claude Code `~/.claude/projects/**/*.jsonl` (включая `claude -p` из launchd) | вызовы через Skill и слэш-команды |
| launchd | `~/Library/LaunchAgents/*.plist` + `launchctl list` | расписание, загружен ли, код последнего выхода, когда писал лог, какую модель Claude зовёт |
| Python | все `*.py` в корнях | кто вызывает (агент), когда меняли, зовёт ли Claude и какую модель, git-репо |

## Аномалии, которые ловит
- 🔴 битый plist; агент вызывает несуществующий скрипт
- 🟠 агент завершился с ошибкой (exit ≠ 0)
- 🟡 лог агента не обновлялся >7 дней; plist лежит, но не загружен; дубли скриптов
- ⚪ скилл ни разу не вызывался

## Статусы скриптов
- **scheduled** — вызывается launchd-агентом
- **manual** — точка входа, но не в расписании (запускается руками или забыт)
- **module** — импортируемый хелпер (`b360_common.py` и т.п.)
- **orphan** — не в расписании и не менялся дольше порога → кандидат на удаление/архив

Ограничение: даты вызова скиллов берутся из журналов Claude Code. Если журналы чистились — ранние вызовы не видны.
